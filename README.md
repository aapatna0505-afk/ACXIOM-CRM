👥 Core Management Modules
The CRM is built around two central modules: Customers and Employees.

1. Customer Management
This section allows you to manage customer records, track interactions, and view history.


Total Customers: The current total is tracked and displayed (e.g., 1 total customer).



Functionality:


Add New Customer: Easily integrate new customer data.


Search/Filter: Search customers by name, email, or phone.



Recent Data: Displays a table of recent customer information, including Name, Email, Phone, and available Actions.


Example Customer: prakhar singh with email harshrai24685@gmail.com and phone 07651938516.

2. Employee Management (Employee Directory)
This module is used to view and manage employee details, roles, and contact information.



Total Employees: The current total staff count is displayed (e.g., 1 total employee).



Functionality:


Add New Employee: Allows for the onboarding of new staff members.


Search: Search employees by name, position, or email.



Current Staff Roster: Displays a table including Name, Email, Phone, Position, and Actions.


Example Employee: Harsh Kumar Rai in the Technical position, with email harshrai24685@gmail.com and phone 07651938516.


📊 Reports & Analytics
The Reports section offers a comprehensive Report Overview with key insights, performance metrics, and business reports.


Key Metrics Displayed:


TOTAL CUSTOMERS: Shows the overall count (e.g., 1).





TOTAL EMPLOYEES: Shows the overall count (e.g., 1).



NEW TODAY (CUSTOMERS): Tracks new customers added on the current day (e.g., 1).



NEW TODAY (EMPLOYEES): Tracks new employees added on the current day (e.g., 1).


Recent Data: Displays a summary of Recent Customers and Recent Employees.


🔍 Search All
The Search All functionality allows users to quickly find information across the entire CRM. For example, searching for "Prakhar" returns 1 Customer Result. The results provide the Name, Email, Phone, and a View action.




⚙️ System Settings
The Settings section manages system and user-specific configurations.



User & Privacy: Displays details such as the user's ROLE (e.g., User) and EMAIL (e.g., harshrai24685@gmail.com). This section displays current session and role information.




Future Modules: Upcoming features include Notifications and Security.



System Notice: Reminds users that all access and activity are subject to system policies.

🚪 Exit

Logout: Provides a secure way to end the current user session.
